# Development Request: Fix Anchor System V2 Downward Swipe Bug

**Date:** 2025-10-31
**Priority:** High
**Source:** Code Review Response (archived: 20251031_204903_code_review_response.md)

---

## Task Summary

Fix the intermittent downward swipe behavior in Anchor System V2 by implementing state capture at gesture start time instead of gesture end time.

---

## Root Cause

**Location:** `MemQuran/ContentView.swift:590-600`

The downward swipe gesture handler evaluates `@State` variables (`anchorWord`, `selectedWord`) at gesture completion time (`.onEnded`), causing a race condition. State can mutate during the swipe gesture, leading to incorrect navigation decisions.

**Current problematic code:**
```swift
DragGesture(minimumDistance: 20)
    .onEnded { value in
        ...
        if let anchor = anchorWord, let selected = selectedWord, anchor > selected {
            jumpToAnchor()
        } else {
            nextVerse()
        }
    }
```

---

## Required Changes

### Primary Fix: Capture State at Gesture Start

**File:** `MemQuran/ContentView.swift`
**Lines:** 554-600 (vertical swipe gesture handler)

#### Implementation Steps:

1. **Add state capture variables** (near other @State declarations)
   - Add variables to store captured `anchorWord` and `selectedWord` values at gesture start

2. **Modify gesture handler to use `.onChanged` + `.onEnded`**
   - Use `.onChanged` to capture state when gesture first begins
   - Use `.onEnded` to evaluate the captured state (not current state)

3. **Apply same fix to upward swipe** (lines 578-588)
   - For consistency and to prevent the same race condition
   - Upward swipes work more reliably but have the same structural vulnerability

#### Suggested Implementation Pattern:

```swift
@State private var capturedAnchorWord: Word?
@State private var capturedSelectedWord: Word?
@State private var hasGestureCapturedState = false

// In gesture handler:
.highPriorityGesture(
    DragGesture(minimumDistance: 20)
        .onChanged { value in
            // Capture state on first change
            if !hasGestureCapturedState {
                capturedAnchorWord = anchorWord
                capturedSelectedWord = selectedWord
                hasGestureCapturedState = true
            }
        }
        .onEnded { value in
            defer { hasGestureCapturedState = false } // Reset for next gesture

            // Use CAPTURED state, not current state
            let verticalTranslation = value.translation.height

            if abs(verticalTranslation) > 20 {
                if verticalTranslation < 0 {
                    // Up swipe
                    if let anchor = capturedAnchorWord,
                       let selected = capturedSelectedWord,
                       anchor < selected {
                        jumpToAnchor()
                    } else {
                        previousVerse()
                    }
                } else {
                    // Down swipe
                    if let anchor = capturedAnchorWord,
                       let selected = capturedSelectedWord,
                       anchor > selected {
                        jumpToAnchor()
                    } else {
                        nextVerse()
                    }
                }
            }
        }
)
```
